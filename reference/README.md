代码前半段主要是第三方库；阅读应用逻辑可从 `zp.assets` 和 `Ry` 开始。`main.readable.css` 提供原始字体、首屏、About、按钮和响应式规则。

本地运行改动集中在：

- `../scripts/prepare-assets.mjs`：已发布资源 → 本地资源，记录哈希；只替换两个 JS 资源 URL，HTML 去掉统计与 Cloudflare loader，CSS 字体改成本地。
- `../public/local.js`：键盘、焦点、加载与 WebGL 错误提示。
- `../server.mjs`：静态文件服务。

`../src/data.js` 是内容对照清单。修改它不会改变运行时；若要改文案，应修改运行脚本 `lm` 数据，并同步对照清单和资源清单校验值。原始捕获证据应保持不变。
